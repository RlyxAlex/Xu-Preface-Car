# Xu-Preface-Car

红外遥控 + 超声波避障小车 · Arduino UNO

用红外遥控一辆小车：按键遥控、超车避让，探头看到障碍物会自动刹车。

---

## 硬件

| 器件 | 说明 |
|------|------|
| Arduino UNO | 主控板（或等价的 ATmega328P 克隆板） |
| L298N 电机驱动 | 双路 H 桥，带散热片 |
| 直流减速电机 × 2 | 带轮子 |
| HC-SR04 超声波 | 装在车头朝前 |
| 红外接收头 + 遥控器 | 38kHz NEC 协议 |
| 蜂鸣器 / LED | 接 A0 |
| 电池 + 开关 | 7.4V~12V 给电机供电 |

---

## 接线

| 信号 | 接到 UNO | 说明 |
|------|----------|------|
| 左轮 IN1 | D5 | 方向 |
| 左轮 IN2 | D7 | 方向 |
| 左轮 ENA | D6 | 调速（PWM） |
| 右轮 IN1 | D8 | 方向 |
| 右轮 IN2 | D10 | 方向 |
| 右轮 ENB | D11 | 调速（PWM） |
| 超声波 Trig | D13 | |
| 超声波 Echo | D12 | |
| 红外接收 OUT | A3 (D17) | |
| 蜂鸣器 + | A0 (D14) | |

电机从 L298N 的 OUT1/OUT2（左）和 OUT3/OUT4（右）出来，模块 GND 和 UNO 的 GND **必须连一起**。

### 供电

- Arduino **单独7.4V供电**
- 电池只接 L298N 的 12V 端子给电机供电
